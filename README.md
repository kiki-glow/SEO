# SEO
## My SEO Journey

- **Crawling** = search engine bots discovering and fetching web pages.
- **Indexing** = processing and sorting information about a page so it can potentially be retrieved for searches.
- **Ranking** = search systems determine which results to show and their ordering for a query.

- A **search query** is what someone types into a search engine.
- **search intent** is what a user is tryna accomplish.

- Semantic HTML e.g. h1...h6, p, section, main, nav, article, etc., is useful for SEO.

```html
    <title></title> 
    
should be descriptive, relevant, concise, and useful to humans.
    <meta
        name="description"
        content="Discover wood-fired pizza, fresh ingredients, and our full menu in Nairobi."
    >
describes the page.
```

- links give search engines a path to discover other pages.
